# LJT-Homepage

Personal homepage of Junteng Liu, built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template.

## Pages

- About (home page): `_pages/about.md`
- Publications: `_pages/publications.html` and `_publications/`
- CV: `_pages/cv.md`

## Configuration

Site settings and contact links are in `_config.yml`; the navigation menu is in `_data/navigation.yml`.
